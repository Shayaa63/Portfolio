# Portfolio — Aisha Hashi

En personlig portfolio och lärandekurva byggd för att visa mina projekt inom fullstackutveckling, frontend-ramverk och backend-logik.

🔗 **Live demo:** [shayaa-portfolio.vercel.app](https://aishahashi.vercel.app/)

---

## 🛠️ Tech Stack & Verktyg

- **Frontend:** React, Next.js, TypeScript, JavaScript (ES6+), HTML5, CSS3, Tailwind CSS
- **Backend & CMS:** Node.js, Express, REST API:er, Storyblok (Headless CMS)
- **Databaser & Övrigt:** PostgreSQL, MongoDB, Python (Skript & Logik från elektronikbakgrund)
- **Verktyg:** Git, GitHub, Vercel, Cursor / AI-assisted workflow

## 📈 Lärandekurva & Struktur

Portfolion är uppbyggd för att visa min utveckling i tydliga steg:
1. **JavaScript-grund:** DOM-hantering och state utan abstraktioner (`Bloggplattform`, `Chattapp`).
2. **React & API:er:** Asynkron datahantering och komponentstruktur (`Pokémon App`).
3. **Next.js & CMS:** Headless CMS-integration och dynamic routing (`Jobbportalen`, `Artikelportalen`).
4. **Backend & Behörigheter:** REST-arkitektur, autentisering och säkerhet i team (`Plot Twist`).
5. **Fullstack-applikation:** Bygga ett komplett system från grunden (`Road2`).

## 💻 Kör lokalt

Klona repot och starta utvecklingsservern lokalt:

```bash

git clone [https://github.com/Shayaa63/portfolio.git](https://github.com/Shayaa63/portfolio.git)

# Gå till projektmappen
cd portfolio

# Installera beroenden
npm install

# Starta utvecklingsservern
npm run dev
