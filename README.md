# Portfolio — Aisha Hashi

Personlig portfolio byggd med Next.js och Tailwind CSS.

🔗 **Live:** https://din-länk.vercel.app

## Tech stack

- Next.js 16
- Tailwind CSS
- TypeScript

## Kör lokalt

```bash
git clone https://github.com/Shayaa63/portfolio.git
cd portfolio
npm install
npm run dev
```

Öppna http://localhost:3000
